One funny single-line sport the Olympics turned down: competitive ghosting — two athletes ignore each other for four years, and the first to text back "sorry, just saw this" is disqualified. A made-up event, real enough to sound like a broadcast, absurd enough to be funny.

## Run it

```sh
python3 main.py
```

The program writes the single line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (1–200 characters).
